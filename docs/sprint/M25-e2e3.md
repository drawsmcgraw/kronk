### Should-fix

**S1. "which the kernel counts as available" would be false for a model
loaded with `--mlock`.** The fresh note says a card's RAM figure includes
memory-mapped model files, "which the kernel counts as available". True
today: the mapped model pages are ordinary page cache (below). A
`llama-server` started with `--mlock` pins those pages; they move to the
unevictable list, leave `MemAvailable`, and sit in used RAM, so in "Other
used RAM". The sentence would then be wrong about that server by the size
of its model file. State named: any llama unit with `--mlock`. Not the
state of this host: no unit in `systemd/` or
`~/.config/systemd/user/llama-*.service` carries `mlock` (grep, 0 hits),
`VmLck` is 0 kB on all five processes, `Mlocked` is 0. The conclusion
("need not fit") is hedged and stays true either way. Does not block the
deploy.

**S2. "A card's RAM figure includes memory-mapped model files" is true of
three of the five cards.** Mapped `.gguf` pages resident in each process
(smaps, 17:30:16): Talkie 13.14 GiB of 14.90; gemma 1.41 of 9.87;
devstral 0.11 of 8.20; both Whisper processes 0 (no model file is mapped;
their file-mapped RAM is libraries, 0.15 GiB each). Read as "this figure
is one that counts mapped model files", which is how the sentence is
used (to explain why the cards can add to more than the segment), it is
true of every card: the figure is `VmRSS`, exactly. Read as "each card's
figure has a mapped model file in it", it is false for the two Whisper
cards in the state I rendered, and nearly empty for devstral, and it
would empty further for any `-ngl 99` server once the kernel reclaims
the mapped pages. I graded it should-fix, not blocker: no figure is
wrong, the sum argument it supports holds (34.22 GiB of card RAM against
a 28.97 GiB segment), and the misreading costs a reader nothing. "can
include" would be true under both readings, and with S1 in mind so would
dropping "which the kernel counts as available" in favour of "which need
not be counted as used". If the coordinator reads it strictly, this is
the one thing that fails.

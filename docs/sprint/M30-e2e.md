## Findings

1. **Blocker, by the brief's definition: the suite fails.** One test,
   from M33, not from this change, and it says nothing about Whisper.
   It needs a fix agent on the M33 test or seed, or the coordinator's
   ruling that it does not hold step A.
2. **Note: the Hub repository has moved.** The request for
   `mobiuslabsgmbh/faster-whisper-large-v3-turbo` is answered with a
   307 to `dropbox-dash/faster-whisper-large-v3-turbo`. So today, at
   every start, production asks a repository under a different owner
   what `main` is and writes the answer into `refs/main`. A new commit
   there would be downloaded and loaded at the next restart. The
   revision came back unchanged this time. This is the case for the two
   lines; the unit's comment could say it.
3. **Note: an offline start cannot repair itself.** If the cache is
   damaged or removed, the start fails where today it would download.
   With `Restart=on-failure`, `RestartSec=5` and no start limit it would
   retry every five seconds without end, and speech recognition would be
   down until someone looks. That is the trade the criteria chose
   (tenet 9, no start limit in this step). The way out is to start once
   without the two variables.
4. **Note: no empty-namespace run** (above). Needs root to allow.
5. **Note: my by-hand environment was smaller than the unit's.** The
   left-out variables are the desktop session's; none bears on the Hub.
   A3's check of the restarted process closes this.
